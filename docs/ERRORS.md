# Исправления ошибок

## 2026-09-27: ключи приложений для белого списка

Причина: обработчик `/my-keys` явно отклонял whitelist без отдельной лицензии,
хотя `effective_access` и `keys_for_user` уже разрешали доступ без оплаты.
Удалена противоречащая общей политике проверка; тексты ответа больше не
предполагают наличие оплаченной подписки.

Проверка: регрессионные сценарии команды и кнопки «Мои ключи» воспроизвели
ошибку до исправления. Покрыты выдача без платежей, срок действия ключа,
отказ без whitelist, ручной запрет, Telegram-бан, отзыв и истечение ключа,
а также отключение выдачи администратором.

Итог: `.venv/bin/pytest -q` завершился успешно, 78 тестов пройдено.
Проверка `git diff --check` не выявила ошибок форматирования.
